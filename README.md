# DataContractual

Sistema web robusto para la creación, gestión y trazabilidad de contratos, enfocado en contadores e instituciones. Desarrollado en PHP y patrón MVC.

## Requisitos

- PHP >= 7.2.34
- MySQL
- Composer

## Instalación

1. Clonar el repositorio
2. Ejecutar `composer install`
3. Importar `database.sql` en MySQL
4. Configurar `App/Config/Database.php`
