DataContractual

Documentación Técnica, Arquitectura y Flujo de Trabajo del Software

1. Descripción del Proyecto

DataContractual es un software web robusto y de alto rendimiento diseñado exclusivamente para que contadores y gestores puedan crear, administrar y disponer de los contratos de diferentes instituciones educativas o clientes/empresas independientes.

Se ha desarrollado con un enfoque especial en la seguridad, protección de datos (trazabilidad y auditoría), rapidez de respuesta (AJAX) y un diseño de interfaz altamente moderno y responsivo (UI/UX).

2. Stack Tecnológico

El sistema está construido garantizando compatibilidad con servidores Legacy, pero aplicando patrones modernos:

PHP 7.2.34 (Compatible con PHP 8) MySQL / PDO Arquitectura MVC (Modelo-Vista-Controlador) Vanilla JS + AJAX (Fetch) jQuery 3.7.1 Bootstrap 5.3 SweetAlert2 (Alertas) DataTables (Tablas dinámicas) Select2 (Búsqueda en selectores) Chart.js (Gráficas) FPDI & TCPDF (Cifrado de PDFs al vuelo) Smalot/PdfParser (Validación Inteligente / OCR)

3. Arquitectura y Seguridad (Módulo de Auditoría)

  • Protección contra Inyecciones: Todas las consultas a la base de datos se realizan usando sentencias preparadas de PDO.
  • Manejo de Contraseñas: Encriptación bcrypt (hash seguro) para usuarios.
  • Control de Sesión: Validación en un Front Controller (index.php) que bloquea el acceso a todas las rutas si no existe una sesión válida.
  • Bitácora de Accesos: Se guarda la IP, fecha y hora de cada inicio de sesión en la tabla bitacora_auditoria.
  • Trazabilidad de Movimientos: Toda tabla importante (Clientes, Plantillas, Contratos) posee los campos actualizado_por (ID del usuario) y actualizado_en (Timestamp), permitiendo auditar quién hizo la última modificación.

4. Flujo de Trabajo (Workflow)

graph TD A([Usuario / Contador]) -->|Ingresa credenciales| B{Validación Login} B -->|Incorrecto| C[Muestra Alerta] B -->|Correcto| D[Inicia Sesión & Registra IP] D --> E[Dashboard Principal] E --> F[Selecciona Vigencia] F --> G[Módulo Clientes] F --> H[Módulo Plantillas] G --> I[Módulo Contratos] H --> I I --> J(Genera Documento PDF/Word) J --> K(Impresión y Firma Física) K --> L([Sube Respaldo Escaneado al Sistema])
  1. Autenticación: El usuario ingresa con sus credenciales (ej. admin@datacontractual.com). El sistema verifica el hash y registra la IP.
  2. Vigencia Automática: El sistema identifica automáticamente el año actual y lo carga en la sesión (Ej. 2026).
  3. Dashboard Principal: El usuario accede a una interfaz premium. Puede cambiar la vigencia desde el menú superior (Selector de años usando Select2). Al cambiar la vigencia por AJAX, la sesión se actualiza y la pantalla se recarga para mostrar datos exclusivos de ese año.
  4. Gestión de Clientes (Fase 3 - Completada): Creación de perfiles (Institución/Independiente). Carga de Foto, Documento Base (NIT) y RUT con validación de Inteligencia Artificial, previsualización en vivo, y descarga cifrada.
  5. Plantillas de Contratos (Próxima): Configuración de textos y variables dinámicas.
  6. Generación de Contratos (Próxima): Cruce entre Cliente y Plantilla para generar PDF/Word.
  7. Firmas y Respaldos (Próxima): Subida del contrato final escaneado.

5. Características Avanzadas (Módulo Clientes)

El Módulo de Clientes integra tecnologías de punta para garantizar seguridad y usabilidad:

  • Gestión de Archivos Estricta: Los archivos se guardan en subcarpetas específicas (fotos/, documentos_nit/, rut/) renombrándose dinámicamente como tipo_nit_id.ext para evitar colisiones. El sistema elimina físicamente (unlink) archivos antiguos o huérfanos de manera automática.
  • Validación Inteligente (AI PDF Parsing): Al subir el RUT, el motor Smalot/PdfParser lee el texto interno del documento y verifica que el NIT escrito en el formulario exista dentro del archivo. Si es un archivo incorrecto, se bloquea la subida preventivamente.
  • Descargas Cifradas (AES): Los PDF se guardan limpios en carpetas privadas. Al descargar, el motor TCPDF + FPDI inyecta cifrado al vuelo usando el NIT del cliente como contraseña obligatoria para abrir el documento.
  • Previsualización Interactiva: Uso extensivo de SweetAlert2 para mostrar vistas previas inmersivas (imágenes y PDFs a 80vh) de archivos cargados en memoria antes de guardar, y miniaturas para archivos ya guardados.
  • UI Responsiva Premium: Interfaz adaptable con DataTables Responsive Extension para ocultar columnas en móviles sin romper el diseño, complementada con un entorno Dark Mode dinámico.

6. Estructura de Base de Datos (Core)

La base de datos se rige por un esquema relacional estricto:

erDiagram ROLES ||--o{ USUARIOS : "posee" USUARIOS ||--o{ BITACORA : "registra acceso" USUARIOS ||--o{ CONTRATOS : "crea / actualiza" VIGENCIAS ||--o{ CONTRATOS : "filtra por año" CLIENTES ||--o{ CONTRATOS : "asociado a" PLANTILLAS ||--o{ CONTRATOS : "sirve de base para" USUARIOS { int id PK string nombre string email int rol_id FK } CLIENTES { int id PK enum tipo "Institucion, Independiente" string documento string nombre_razon_social } CONTRATOS { int id PK int cliente_id FK int plantilla_id FK int vigencia_id FK string estado }
  • roles: Define niveles de acceso (Ej. Administrador, Usuario).
  • usuarios: Personas con acceso al sistema.
  • vigencias: Años fiscales de operación (Ej. 2024, 2025, 2026). Aisla los datos de contratos.
  • clientes: Instituciones o personas a quienes se les hace un contrato.
  • plantillas_contrato: Formatos maestros de los documentos legales.
  • contratos: El documento generado para un cliente específico, asociado a una vigencia.
  • bitacora_auditoria: Historial de logins y eventos críticos de seguridad.

7. Diseño UI/UX y Modo Oscuro

El sistema cuenta con una interfaz premium adaptable:

  • Diseño Responsivo: Adaptación perfecta a móviles, tablets y escritorio. Sidebar lateral colapsable (modo íconos).
  • Dark Mode Nativo: Utilización del sistema `data-bs-theme="dark"` de Bootstrap 5 para garantizar alto contraste y legibilidad. Efectos de cristal (glassmorphism) en tarjetas con fondos corporativos en degradado.
  • Adaptabilidad en Tiempo Real: Botón toggle para cambiar el tema y guardado automático en `localStorage`.

Desarrollado para garantizar rapidez, confianza y experiencia premium en la gestión contractual.
